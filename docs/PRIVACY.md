# Lenshelf 隐私说明

Lenshelf 是本地运行的分类相机，不申请网络权限，也不包含账号、广告、统计或云同步功能。

## 使用的权限

- **相机**：取景、拍照、Live 图和独立录像。
- **麦克风**：为 Live 图和独立录像录音。拒绝麦克风权限后，普通拍照仍可使用；支持的系统上 Live 可降级为无声。
- **用户选择的目录**：通过 Android Storage Access Framework 取得持久读写授权，仅访问用户明确选择的根目录及其分类子目录。

## 数据保存

照片、Motion Photo 和视频直接保存到用户选择的目录。分类、设置和未完成保存任务记录保存在设备本地。应用不会主动把媒体、目录信息、相机数据或日志发送到网络。

Debug 构建包含仅供开发验证使用的 Camera2 探针和本地诊断日志；正式发布应使用 Release 构建。卸载应用不会自动删除已经保存到用户目录中的媒体。

## 用户控制

用户可以在 Android 系统设置中撤销相机、麦克风和目录访问权限。分类删除默认保留文件夹和媒体；只有在删除确认框中主动勾选同步删除时，应用才会删除对应分类目录及其中内容。

# Lenshelf 隐私说明

Lenshelf 是本地运行的分类相机，不申请互联网访问权限，也不包含账号、广告、统计或云同步功能。

## 使用的权限

- **相机**：取景、普通拍照、文档拍照和独立录像。
- **麦克风**：仅用于独立有声录像。拒绝麦克风权限后，普通和文档拍照仍可使用，录像不会开始。
- **用户选择的目录**：通过 Android Storage Access Framework 取得持久读写授权，仅访问用户明确选择的根目录及其分类子目录。
- **网络状态**：视频处理依赖声明读取网络连接状态的权限；应用不申请互联网访问权限。

## 数据保存

已归档的照片和视频保存在用户选择的目录。分组、分类、相机设置、备注草稿、目录操作日志及未完成任务保存在设备本地。文档识别和处理使用随 APK 提供的本地 OpenCV，不下载扫描组件，也不将图片发送到服务器。

时间水印使用设备当地时间，不访问网络或定位。照片使用快门接受时的时间，视频使用开始录制时的时间；水印、拍后备注及其他相机设置按分类保存在本机。

文档照片自动处理后保存，普通照片和视频可按设置等待备注或添加水印。待备注原件、处理原件和输出材料保存在应用私有目录，备注草稿保存在本地数据库；目标文件完整写入并读回校验成功后才清理对应材料。处理或写入失败时保留材料供重试，待备注素材需用户确认后才能继续归档。

转移分类会移动当前授权根目录中的整个分类目录，包括隐藏文件、非媒体文件及子目录；复制回退先完整读回并核对 SHA-256，再清理源目录，不合并或覆盖目标同名内容。日志包含源、目标位置、文件清单和校验进度，保存在应用私有目录供中断恢复，不上传网络。

从旧版升级时，常用分类可能需要迁入实体“常用”文件夹，同样使用可恢复移动和校验；旧版未确认文档草稿仍需用户明确保存或丢弃。既有媒体不会因升级而追加水印、删除或改写。

应用不会主动把媒体、目录信息、相机数据或日志发送到网络；文档临时材料目录已排除 Android 自动云备份和设备迁移。本地采集诊断日志用于排查拍摄与保存问题，保存在应用私有目录，分享前须去除私人分类、路径和设备标识。

**卸载应用或清除应用数据会删除私有的待备注素材、处理材料、草稿、任务和设置**。已经保存到用户授权目录中的媒体不会因此自动删除；尚未归档的素材不能依赖这些目录保留。

## 用户控制

用户可以在 Android 系统设置中撤销相机、麦克风和目录访问权限。从分类菜单删除或拖入垃圾桶后，应用均先显示确认框；确认后删除实际分类文件夹及全部内容，包括照片、视频、子目录和其他文件。刷新分类只根据目录是否存在同步软件记录，不删除实际媒体；读取失败或仍有关联待处理材料时不会直接移除分类记录。

# Lenshelf 隐私说明

Lenshelf 是本地运行的分类相机，不申请网络权限，也不包含账号、广告、统计或云同步功能。

## 使用的权限

- **相机**：取景、普通拍照、文档拍照和独立录像。
- **麦克风**：仅用于独立有声录像。拒绝麦克风权限后，普通和文档拍照仍可使用，录像不会开始。
- **用户选择的目录**：通过 Android Storage Access Framework 取得持久读写授权，仅访问用户明确选择的根目录及其分类子目录。

## 数据保存

照片和视频保存到用户选择的目录。分类、设置、文档处理材料、旧版未确认草稿和未完成保存任务记录保存在设备本地。文档识别和处理使用随 APK 提供的本地 OpenCV，不下载扫描组件，也不将图片发送到服务器。

0.7.1 文档拍摄后自动处理并保存，无需另一次确认。原图只保存在应用私有目录，分类目录只写入处理后的 JPEG；目标文件完整写入并读回校验成功后才清理原图和处理材料。处理或写入失败时保留材料供重试，离开相机或进程重启不会取消完整材料的保存。0.7.0 遗留未确认草稿不因升级自动归档，用户可从首页明确保存或丢弃。既有动图文件不因升级而删除或改写。

应用不会主动把媒体、目录信息、相机数据或日志发送到网络；文档临时材料目录已排除 Android 自动云备份和设备迁移。本地采集诊断日志用于排查拍摄与保存问题，保存在应用私有目录，分享前须去除私人分类、路径和设备标识。正式发布应使用 Release 构建。卸载应用会清除私有草稿、任务和设置，但不会自动删除已经保存到用户授权目录中的媒体。

## 用户控制

用户可以在 Android 系统设置中撤销相机、麦克风和目录访问权限。分类删除默认保留文件夹和媒体；只有在删除确认框中主动勾选同步删除时，应用才会删除对应分类目录及其中内容。

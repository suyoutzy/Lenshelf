# Lenshelf 品牌说明

**Lenshelf** 由 Lens（镜头）和 Shelf（收纳架）组合，表达“拍摄时即归档”：先选择分类，再把照片和视频保存到对应文件夹。

## 名称与定位

- 产品名称统一写作 **Lenshelf**，不拆分、不翻译。
- 产品定位：Android 分类相机。
- 简介：先选分类，再拍摄，照片和视频直接保存到对应文件夹。

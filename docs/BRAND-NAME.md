# 品牌名称

## 已确定

**Lenshelf**：由 Lens（镜头）和 Shelf（分层收纳）组合，表达“拍摄时即归档”的产品定位。自 0.2.1 起作为正式应用名。

## 推荐：Lenshelf

- 组合：`Lens + Shelf`
- 含义：镜头拍下内容，并立刻放到对应“架子”上。
- 优点：简洁、好读、品牌感较强，能同时暗示拍摄与有序收纳。
- 中文读法建议：兰摄尔夫；产品界面只使用英文拼写。

## 其他候选

| 名称 | 构成 | 特点 |
|---|---|---|
| FocalFile | Focal + File | 稍偏专业工具感，强调拍摄与文件落盘 |
| PicRoute | Picture + Route | 直接表达“把照片路由到指定目录” |
| Lensort | Lens + Sort | 功能最直白，但读感比 Lenshelf 更技术化 |
| FrameFold | Frame + Folder/Fold | 好记且有摄影感，但已有同名设计公司，商业使用前不建议优先 |

## 已排除的名称

- `SnapNest`：已有高度相似的 Android 拍摄整理应用。
- `SortShot`：已有照片整理应用及 macOS 截图整理产品。
- `TidyShot`：已有 iPhone 与 macOS 照片/截图整理产品。
- `FoldCam`：已有与本产品理念非常接近的旧 Android 应用。
- `FileLens`、`FolderLens`、`SnapShelf`：已有在用的软件或服务名称。

以上只是基础网络重名筛查，不等同于商标、公司名称、域名和各国家应用商店的完整法律检索。正式公开发布前应再次检索目标市场。

# Lenshelf 使用指南

本指南对应 0.9.1，支持 Android 10 及以上。安装包和版本说明见 [GitHub Releases](https://github.com/suyoutzy/Lenshelf/releases/latest)。

## 保存位置与首次使用

首次启动时选择一个可长期访问的根目录。照片、文档 JPEG 和视频统一按 `根目录／一级文件夹／分类` 保存；“常用”也对应根目录下的实际文件夹，不汇总其他文件夹的内容。

首页底栏点击或左右滑动均可切换一级文件夹；滑到两端后停止，不循环。顶部“＋”在当前文件夹下新增分类，底栏的文件夹加号新建一级文件夹。

点击分类进入相机。点击分类卡片上的文件夹图标，或在首页设置中选择“打开根目录”，可交给系统文件管理器查看媒体。打不开时，可检查设置中的文件管理器兼容选项。

## 照片、录像与文档

- **照片**：在“照片”模式短按快门。支持变焦、闪光、点按对焦和曝光补偿。
- **录像**：在“照片”模式长按快门开始有声录像，支持暂停和继续。需要麦克风权限；拒绝后仍可拍照，但录像不会开始。录像沿用照片取景时选择的倍数，同一镜头返回拍照后保留倍数。
- **文档**：切换到“文档”后按快门，自动识别纸页、裁剪、透视矫正并保存。识别不可靠时保留全图。成片会短暂展开预览，可继续拍下一张；预览不代表已完成保存。

文档效果可直接点击模式旁的“效果”入口选择，也可在相机设置中选择：

| 效果 | 行为 |
|---|---|
| 原色 | 保留颜色，仍进行裁剪与透视矫正 |
| 增强 | 尝试减轻灰暗和局部阴影，保护彩色笔迹与细线；暗底和彩色底采用保守处理 |
| 黑白 | 转为灰度 |

摊开笔记本时默认选择靠近画面中心的一页。曲面书页、反光或复杂背景可能影响识别；当前不提供拍后四角编辑、OCR 或多页 PDF。

## 每个分类的相机设置

相机设置按分类独立保存。重命名或转移分类后，设置继续跟随该分类。

| 设置 | 默认值 |
|---|---|
| 时间水印 | 开启，仅日期 |
| 同步防抖 | 开启；是否实际生效取决于设备和绑定结果 |
| 井字格 | 关闭 |
| 拍后备注 | 关闭 |
| 闪光灯 | 关闭 |
| 文档效果 | 原色 |

0.9.1 的已有分类与新分类均从这些默认值开始，不沿用旧版全局相机设置。后续修改只影响当前分类；已经接受的拍摄任务继续使用拍摄时确定的设置和保存位置。

## 时间水印

普通照片和视频共用开关与格式：仅日期（如 `2026-11-23`），或日期加时分（如 `2026-11-23 14:35`），均使用设备当地时间和 24 小时制。

照片使用快门被接受时的时间；视频整段使用开始录制时的时间，暂停和继续不会更新。之后修改时间格式、时区或重试，也不会改变已拍素材的时间文字。水印位于右下角，采用白字配深色描边。

文档照片不添加时间水印或拍后备注；升级也不会给已有素材追加水印。

## 拍后备注与待处理

在需要此功能的分类中开启“拍后备注”，普通照片和视频拍完后会先进入待备注列表。

- 拍摄前没有待备注项，且仍在原相机页面前台时，符合弹框条件的素材会自动打开填写框。已有待处理项时，后续拍摄直接加入列表。
- 填写框展示预览、原目标分类和处理位置。备注最多 60 个 Unicode 字符，单段输入；文字可自动换行。
- 点击“收起”、返回或滑动关闭，会保留素材与已写入的草稿。写入失败时会提示，先处理错误再收起。
- 点击“保存”后，确认该项备注并交给后台处理、保存，再打开下一项。队列已满时输入和素材仍保留，可稍后重试。
- 留空保存时，开启时间水印则只添加时间；时间也关闭时保存原素材。备注位于时间上方，两者可单独使用。

相机取景框右下角的“待处理 N”和首页的“待备注”入口统计所有分类中已拍完、尚未确认备注的素材，按拍摄顺序打开。录像期间隐藏相机入口。后台处理、保存及失败状态分别显示，不计入待备注数量。

关闭拍后备注只影响之后的拍摄，不清空已有待备注项。离开相机或重启后可通过入口继续填写，不补弹自动填写框。归档完成后，本版不支持再次编辑备注。

## 分类和文件夹管理

- **分类改名或删除**：分类卡片“⋮”菜单。删除包含实际分类目录及所有内容；拖入垃圾桶也会打开同一个确认框，确认前不会删除。
- **分类排序**：长按卡片拖动，在同一列表内松手保存顺序。
- **转移分类**：拖动卡片，在底部目标文件夹上悬停约 600 毫秒预览其列表，再回到目标列表指定位置松手。仅在文件夹入口上松手、拖回或取消，不移动文件。
- **文件夹排序**：长按底栏自定义文件夹标签，左右拖动。“常用”固定最前，不可改名、删除或排序。
- **文件夹改名或删除**：当前自定义文件夹旁的“⋮”菜单；只有没有分类且实际目录完全为空时才允许删除。

转移会搬动整个分类目录，包括子目录、隐藏文件和其他文件；目标同名时拒绝合并或覆盖。有关联待备注、待保存任务、失败材料或旧草稿的分类，先处理这些材料后再改名、删除或转移。

### 刷新分类

顶部刷新按钮只同步当前一级文件夹的直属分类目录，并更新文件数量：补入实际存在的新目录，移除实际目录已不存在的分类记录，保留仍存在的空目录。刷新不删除实际媒体。外部重命名按旧分类移除、新分类加入处理。

读取不完整、授权失效或有关联未完成材料时，不会直接移除相关记录。隐藏目录、无效名称及首尾带空白的目录会忽略；存在仅大小写不同的同名目录时，需先解决冲突再刷新。

## 保存、恢复与升级

“已提交保存”表示任务已排队，目标文件完成完整读回校验后才算保存成功。处理或写入失败时保留原件供重试；看到失败提示时，从首页任务入口处理。

处理、保存和可重试任务共用 8 项活动容量；待备注项不占此容量，但仍占用设备空间。空间不足或活动任务已满时，新的拍摄或备注确认会被暂缓。

切换分类或根目录只影响后续拍摄，旧任务继续使用其冻结位置。目录移动期间不能更换根目录；原目录授权失效时，需要重新授权原目录。离开相机后可继续处理，进程中断后下次启动恢复；应用不保证退出后持续执行。

从旧版升级时，旧常用分类可能需要迁入 `根目录／常用`；目标重名或仍有待处理材料时会暂停，迁移完成前不能更换根目录。0.7.0 遗留文档草稿仍需在首页明确保存或丢弃。其他历史变化见[版本记录](../CHANGELOG.md)。

正式版与调试版的签名不同，不能直接相互覆盖。不要通过卸载或清除应用数据解决签名冲突：这会清除私有的待备注素材、草稿、任务和设置；已归档到授权目录的媒体不会因此自动删除。
